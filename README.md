# Works To Be Done

A simple to-do list with a dark **neumorphism** design, built with HTML, CSS and JavaScript.

## Live Demo

[Open the live project](https://elhammohmand2006-stack.github.io/neumorphism-todo-list/)

## Features

- Add a new task to the bottom of the list
- Delete any task with one click
- Empty tasks are not allowed
- Soft, dark neumorphism design (raised cards and pressed-in input)

## Technologies

- HTML
- CSS
- JavaScript

## Project Structure

```
neumorphism-todo-list/
├── index.html   # page structure
├── style.css    # neumorphism styles
└── script.js    # add and delete logic
```

## How to Use

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Type a task and click **Add Task**.
4. Click **Delete** to remove a task.

## What I Learned

- Creating elements with JavaScript (`createElement`, `appendChild`)
- Handling click events (`addEventListener`)
- Removing elements from the page (`remove`)
- Using separate CSS and JS files
- Making a neumorphism style with `box-shadow` and `inset`
